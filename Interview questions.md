# 1. What does a Data Engineer do?

A Data Engineer builds and maintains data pipelines that collect, store, clean, transform, and deliver data so it can be reliably used for reporting, analytics, and machine learning.

&nbsp;

&nbsp;

# 2. What is a data pipeline?

A data pipeline is a sequence of automated steps that moves data from source systems to a target system while performing ingestion, validation and transformation.

&nbsp;

&nbsp;

# 3. What is the difference between ETL and ELT?

In ETL, data is transformed before loading. In ELT, raw data is loaded first and transformed inside the target data warehouse.

&nbsp;

&nbsp;

# 4. Why is ELT commonly used with Snowflake?

Snowflake supports ELT because it separates storage from compute. Raw data can be loaded into scalable cloud storage first, and SQL or dbt transformations can then run using independently scalable virtual warehouses. This reduces dependence on external transformation servers and allows compute capacity to be adjusted according to workload size.

&nbsp;

&nbsp;

# 5. Why do Data Engineers use Git?

Git tracks code changes, supports collaboration, allows previous versions to be restored and enables pull-request and CI/CD workflows.
