# Arguments in Terraform variable Block

In Terraform, a variable block lets you declare an input variable.

Inside the block, you can use several arguments to control how the variable behaves.

&nbsp;

&nbsp;

# All Common Arguments in Terraform Variables

| Argument      | Purpose                              |
| ------------- | ------------------------------------ |
| `type`        | Defines data type                    |
| `default`     | Sets fallback value                  |
| `description` | Helps humans understand the variable |
| `validation`  | Enforces rules                       |
| `sensitive`   | Hides value in logs                  |
| `nullable`    | Allows or rejects null               |
|               |                                      |
