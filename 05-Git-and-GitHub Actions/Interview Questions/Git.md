# Basic Git Questions

1. What is Git?

   A distributed version control system used to track changes in source code.

2. Difference between Git and GitHub?

   Git is a tool; GitHub is a cloud-based platform that hosts Git repositories.

3. What is a repository?

   A storage location for a project, including its commit history.

4. What is a commit?

   A snapshot of changes made to files at a specific point in time.

5. What is the Git workflow?

   Working Directory → Staging Area → Repository.

6. What does git status do?

   Shows the state of the working directory and staging area.

7. What is git clone?

   Creates a local copy of a remote repository.
