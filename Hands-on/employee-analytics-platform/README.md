# Employee Analytics Data Platform

## Objective

Build an end-to-end data engineering pipeline that:

1. Reads employee data from CSV files using Python.
2. Validates and cleans the source data.
3. Loads the data into Snowflake.
4. Transforms the data using SQL and dbt.
5. Implements data-quality tests.
6. Provisions Snowflake resources using Terraform.
7. Automates validation using CI/CD.

## Technologies

- Python
- SQL
- Snowflake
- dbt
- Terraform
- Git and GitHub
