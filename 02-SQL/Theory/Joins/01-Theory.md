# JOINs

JOIN means to combine something.

A JOIN combines data from multiple tables using a common column (key).

In SQL, JOINs are used to combine rows from two or more tables based on a related column between them.

&nbsp;

👉 Think of it like:

- Table A = Users
- Table B = Orders
- JOIN = “Which user placed which order?”

&nbsp;

&nbsp;

# Common Types of SQL JOINs

- INNER JOIN
- LEFT JOIN / LEFT (OUTER) JOIN
- RIGHT JOIN / RIGHT (OUTER) JOIN
- FULL OUTER JOIN
- CROSS JOIN
- SELF JOIN
