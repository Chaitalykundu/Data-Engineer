A table stores data using rows and columns.

&nbsp;

&nbsp;

| EMPLOYEE_ID | EMPLOYEE_NAME | DEPARTMENT_ID | SALARY |

|         102 | Priya         |            20 |  60000 |

&nbsp;

# Rows and columns

- A row represents one complete record.
- A column represents one attribute of the records.

&nbsp;

&nbsp;

# Example `EMPLOYEES` table

| EMPLOYEE_ID | EMPLOYEE_NAME | DEPARTMENT_ID | SALARY |
| ----------: | ------------- | ------------: | -----: |
|         101 | Amit          |            10 |  75000 |
|         102 | Priya         |            20 |  60000 |

&nbsp;

Here:

- `101`, `Amit`, `10`, `75000` is one row.
- `SALARY` is one column.
- `75000` is a column value.

&nbsp;

&nbsp;

A fully qualified Snowflake table name follows this format:

```
DATABASE_NAME.SCHEMA_NAME.TABLE_NAME
```
