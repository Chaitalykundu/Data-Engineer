# Keys are used to

- uniquely identify rows
- create relationships between tables
- maintain data integrity

They are one of the most important concepts in databases.

&nbsp;

&nbsp;

# Types of Keys in SQL

| Key Type      | Purpose                                      |
| ------------- | -------------------------------------------- |
| Primary Key   | Uniquely identifies each row                 |
| Foreign Key   | Creates relationship between tables          |
| Unique Key    | Prevents duplicate values                    |
| Composite Key | Combination of columns acting as key         |
| Candidate Key | Possible columns that can become primary key |
| Alternate Key | Candidate key not selected as primary key    |
| Super Key     | Any column(s) uniquely identifying rows      |
| Surrogate Key | Artificial/generated key                     |
