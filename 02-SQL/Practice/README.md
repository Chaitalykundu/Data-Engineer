# SELECT

## Practice Questions

1. Write a query to display all columns from Employees.
2. Display only:
   - employee_name
   - salary
3. Show unique department names.
4. Display employees with aliases:
   - employee_name AS Name
   - salary AS MonthlySalary
5. Show all employees ordered by salary descending.

&nbsp;

## Interview Questions

- Difference between SELECT \* and selecting specific columns?
- What does DISTINCT do?
- Difference between WHERE and HAVING?
- What is alias in SQL?
- Why avoid SELECT \* in production?

# WHERE Clause & Filtering

## Practice Questions

1. Find employees with salary greater than 50000.
2. Find employees from Kolkata.
3. Find employees whose salary is between 40000 and 70000.
4. Find employees from:
   - Kolkata
   - Delhi
5. Find employees NOT from Mumbai.
6. Find employees whose name starts with A.
7. Find employees whose name ends with n.
8. Find employees whose name contains ar.
9. Find employees where salary is NULL.
10. Find employees hired after 2023-01-01.

&nbsp;

## Interview Questions

- Difference between = and LIKE
- What is % and \_ in LIKE?
- Difference between NULL and 0
- Why salary = NULL does not work?
