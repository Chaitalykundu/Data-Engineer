# What is an IAM Role?

An IAM Role (Identity and Access Management Role) is an identity in AWS that provides temporary permissions to a trusted person, application, or AWS service to access specific AWS resources.

Unlike an IAM User, an IAM Role does not have permanent credentials such as a username, password, or long-term access keys.

Instead, AWS generates temporary security credentials when an authorized entity assumes the role.
