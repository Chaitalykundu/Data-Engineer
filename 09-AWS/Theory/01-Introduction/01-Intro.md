AWS (Amazon Web Services) is a cloud platform that provides services for storage, computing, networking, data processing, security and analytics.

&nbsp;

&nbsp;

In a Data Engineering project, you might use:

- **S3**: stores incoming files and data lake datasets.
- **Lambda**: executes lightweight Python code, such as fetching API data.
- **Glue**: discovers, transforms and processes data.
- **Redshift**: stores data for analytics.
- **IAM**: controls who or what can access these services.
- **CloudWatch**: captures logs, metrics and alerts.

&nbsp;

Think of AWS as the infrastructure on which you build your data pipeline.
