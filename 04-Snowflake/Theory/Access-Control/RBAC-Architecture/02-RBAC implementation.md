# Practical RBAC implementation

Suppose analysts require read-only access to the `EMPLOYEES` table, steps are

1. Create the role
2. Grant warehouse access
3. Grant database access
4. Grant schema access
5. Grant table access
6. Assign the role to a user
7. Add it to the hierarchy
