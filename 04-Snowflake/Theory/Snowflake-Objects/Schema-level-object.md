# Schema level object

| Category         | Objects                               |
| ---------------- | ------------------------------------- |
| Data Storage     | Tables                                |
| Data Access      | Views, Secure Views                   |
| Performance      | Materialized Views                    |
| Data Engineering | Streams, Tasks, Pipes                 |
| Logic            | Functions, Procedures                 |
| Data Loading     | Stages, File Formats                  |
| Security         | Masking Policies, Row Access Policies |
| Utility          | Sequences, Tags                       |

&nbsp;

These objects are created inside a schema, unlike:

- Warehouse (account-level)
- Database (higher level)
